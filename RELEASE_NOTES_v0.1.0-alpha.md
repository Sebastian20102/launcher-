# Nexus Launcher v0.1.0 Alpha

First public alpha for Nexus Launcher on Windows.

## Highlights

- Local library per Windows user.
- Add programs, executables, folders and project directories.
- Glass interface with smoother motion and animated layout changes.
- Custom wallpapers with image, GIF and video support.
- Nexus Copilot with local memory and LM Studio, Ollama or OpenAI-compatible provider support.
- AI timeout protections so the chat does not stay stuck thinking forever.
- Clean distribution mode: creator library, generated icons, AppData files and API keys are not bundled.

## Important Alpha Notes

- This is an early alpha, not a stable v1 release.
- Windows may show a warning because the app is not code-signed with a public certificate yet.
- The app stores user data locally in `%APPDATA%\Nexus Launcher`.
- AI features require a configured local provider or API key.
